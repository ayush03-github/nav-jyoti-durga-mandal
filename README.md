# Nav Jyoti Durga Mandal (NJDM)

A modern, responsive devotional web application for Nav Jyoti Durga Mandal featuring Hindi bhajans, aartis, chalisas, mantras, and stotrams.

## Tech Stack
- Next.js (App Router)
- React 18
- Tailwind CSS
- Lucide React
- TypeScript

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
