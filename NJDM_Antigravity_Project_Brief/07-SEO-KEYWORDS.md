# NJDM SEO Strategy & Keyword File

## Purpose

This file is intentionally separate from the main project brief.

Use it as the SEO source of truth for:
- page metadata
- title templates
- descriptions
- keyword planning
- content SEO
- internal linking
- structured data planning

Do not keyword-stuff pages.

## Deity keyword pattern

For each deity, support combinations such as:

`[deity] bhajan`

`[deity] bhajan lyrics`

`[deity] aarti`

`[deity] aarti lyrics`

`[deity] chalisa`

`[deity] mantra`

`[deity] stotram`

Examples:
- Hanuman bhajan
- Hanuman bhajan lyrics
- Hanuman aarti
- Hanuman chalisa
- Shiv bhajan
- Shiv aarti
- Krishna bhajan
- Krishna aarti
- Durga bhajan
- Durga aarti
- Ganesh bhajan
- Ganesh aarti

Do not assume every deity has every content type.

## Festival keyword pattern

For each festival:

`[festival] bhajan`

`[festival] aarti`

`[festival] mantra`

`[festival] devotional songs`

Examples:
- Navratri bhajan
- Navratri aarti
- Janmashtami bhajan
- Ganesh Chaturthi aarti
- Ram Navami bhajan
- Shivratri bhajan

## Organization keywords

Use organization-specific keywords only where factually appropriate:

- Nav Jyoti Durga Mandal
- NJDM
- Nav Jyoti Durga Mandal bhajan
- Nav Jyoti Durga Mandal aarti

Do not manufacture local location keywords unless the organization confirms its location.

## Search indexing

Create indexable individual content pages.

Avoid indexing:
- internal admin-like routes if later added
- duplicate filtered URLs
- unnecessary query parameter combinations

## Sitemap

Generate an XML sitemap containing:
- homepage
- category pages
- deity pages
- festival pages
- individual content pages

## Robots

Create an appropriate robots configuration allowing public content pages to be crawled.

## Canonical URLs

Every indexable page should have a canonical URL.

## Open Graph

Every individual content page should have:
- title
- description
- suitable image
- canonical URL

Use a temporary image until official NJDM social images are provided.

## Structured data

Where appropriate, implement valid Schema.org structured data for:
- WebSite
- BreadcrumbList
- Article/CreativeWork-style content where appropriate

Do not claim unsupported properties.

## Internal linking

Content pages should link to:
- same deity content
- same category
- relevant festival
- related devotional items

Category pages should link to individual content pages.

## Content SEO rule

Do not add awkward keyword-filled paragraphs.

The lyrics themselves are the core content.

Use:
- accurate titles
- useful descriptions
- meaningful metadata
- strong internal linking
- clean URLs
- fast page performance
- proper headings

## Future SEO content

Leave room for future:
- festival landing pages
- deity guides
- devotional collections
- informational articles

Do not build an article/blog system unless required later.
